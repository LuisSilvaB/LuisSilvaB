### 👨‍💻 About Me

I am a **Software Engineer & AI Agent Developer** with a degree in Computer & Systems Engineering, dedicated to building production-grade autonomous agentic workflows and scalable software platforms. 

My primary focus is bridging large language models (LLMs) with actionable real-world capabilities—designing intelligent systems that can reason, orchestrate multi-step tasks, call custom tools, and integrate seamlessly with enterprise backend services.

---

### 🤖 What I Do — AI Agent Engineering

Currently working actively on the design, architecture, and deployment of intelligent agent systems:

- 🧠 **Agentic Orchestration:** Architecting graph-based multi-agent systems using **LangGraph** and **LangChain**, managing dynamic state graphs, decision branches, and tool orchestration.
- 💬 **Conversational AI & Channels:** Developing context-aware conversational agents deployed to channels like **WhatsApp**, managing dialogue state, intent classification, and real-time interaction.
- 🔌 **Tool Calling & External Integrations:** Connecting LLM agents to custom REST APIs, database tools, scraping pipelines, and external platforms for deterministic execution.
- ⚡ **Backend & High-Performance Services:** Building high-throughput backend services and APIs using **Python (FastAPI)** and **TypeScript (Bun / Elysia / Node.js)** to power agent tools and business logic.
- 🛡️ **Reliability & Validation:** Enforcing strict schema validation, structured JSON outputs with Pydantic/Zod, prompt optimization, and error recovery strategies for dependable agent behavior.
